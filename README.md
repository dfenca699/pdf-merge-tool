# PDF Merge Tool

A simple desktop tool for merging and organizing PDF files locally.

## Features

- Merge multiple PDF files into one document
- Organize PDF files locally on your computer
- Simple interface for non-technical users
- No need to upload private documents to online services

## Why I built this

Many students, freelancers, and office users often need a simple way to merge and organize PDF files.  
This project aims to provide a lightweight local desktop tool for common PDF workflows.

The goal is to make document handling easier for users who do not want to rely on online PDF websites or upload private files to third-party services.

## Usage

1. Open the application
2. Select the PDF files you want to merge
3. Choose the output location
4. Click the merge button
5. Save the merged PDF file locally
